- پنل مدیر شامل مدیریت کارکنان، چاپ کارت QR، تغییر PIN، تعویض QR، فعال/غیرفعال‌سازی و بک‌آپ است.
- نقش‌های مستقل `owner` و `store_manager` روی پایگاه داده اصلی ایجاد شده‌اند.
- حساب مالک `mahdi.alaei64@gmail.com` نقش `owner` دارد.
- حساب مدیر فروشگاه `ahoora7000@gmail.com` نقش `store_manager` دارد.
- نام فروشگاه در تنظیمات پایگاه داده «موبایل ارغوان» است.
- توابع سمت سرور برای دعوت مدیر، پذیرش دعوت، تعیین مدیر برای حساب تأییدشده، فهرست مدیران، فهرست دعوت‌ها، لغو دسترسی مدیر توسط مالک و لغو دعوت اضافه شده‌اند.
- پنل شاخه توسعه برای مدیریت چرخه مدیر توسط مالک به‌روزرسانی شده است.
- آزمون SQL نقش‌ها با rollback اجرا شده است.
- PR شماره ۱ در GitHub باز است؛ هنوز ادغام نشده است.

### مانده برای تکمیل مرحله مدیریت
- تعیین دامنه نهایی سایت و ثبت آن در Supabase Auth Redirect URLs.
- تنظیم secrets امن Edge Function شامل `APP_URL` و `APP_ORIGIN` و deploy تابع `invite-manager`.
- آزمایش واقعی ایمیل دعوت، ورود، پذیرش دعوت و لغو دسترسی.
- بررسی تنظیمات قالب ایمیل Supabase Auth.
- بررسی دسترسی مدیران قدیمی و جلوگیری از قفل‌شدن مالک.

## مرحله بعد — تکمیل هسته حضور و غیاب
1. بررسی کامل جریان‌های کیوسک، محاسبه ساعت، شیفت باز و سوابق.
2. افزودن گزارش‌های روزانه/ماهانه و فیلتر کارکنان به پنل مدیر.
3. افزودن مرکز بررسی رکوردهای `needs_review` و امکان اصلاح با ثبت دلیل و ممیزی.
4. بهبود پشتیبان‌گیری: حذف وابستگی به مرتب‌سازی بر اساس ستون ناموجود، بررسی صفحه‌بندی و افزودن بازیابی کنترل‌شده.
5. بازبینی و محدودسازی مجوز اجرای RPCها، به‌ویژه توابع `SECURITY DEFINER`.

## مرحله بعد — پرتال کارکنان
- ایجاد هویت اختصاصی کارمند و ورود امن.
- نمایش فقط سوابق همان کارمند.
- ثبت درخواست اصلاح حضور/خروج با وضعیت، دلیل و تاریخچه.
- تأیید یا رد درخواست توسط مدیر مجاز.

## قابلیت اختیاری — NFC و GPS
- پشتیبانی NFC به‌عنوان راه‌انداز ثبت حضور.
- دریافت GPS با رضایت کاربر و اعتبارسنجی فاصله در سمت سرور.
- ثبت زمان سرور، دقت GPS، نتیجه اعتبارسنجی و جلوگیری از درخواست تکراری.
- NFC/GPS به‌تنهایی اثبات قطعی حضور نیستند و باید با کنترل‌های تکمیلی همراه شوند.
